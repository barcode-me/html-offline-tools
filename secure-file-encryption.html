Secure file encryption

Encrypt files or text with a password. Everything runs locally in your browser; nothing is uploaded or saved by the page.

Operation
Input

Use a strong, unique passphrase. A forgotten password cannot be recovered.

Result

Download

AES-256-GCM · PBKDF2-SHA-256 · 600,000 iterations · random 16-byte salt and 12-byte IV. Files are processed in memory; available browser memory limits file size.

Binary format and compatibility

Binary format version 2 (.wec) encrypts original bytes directly, including the filename. It does not read the original page’s JSON containers or version 1 / 100,000-iteration encryption. Optional Base64 text represents the exact same binary file for copy and paste; downloads never use Base64.

All offsets are absolute, zero-based. Multi-byte integers are unsigned, little-endian. The entire 44-byte header is authenticated as AES-GCM additional data.
