Yeti encoder and decoder

Encode UTF-8 text or the raw bytes of any file as case-sensitive Yeti phonetic rows.

Runs entirely in your browser. Nothing is sent over the network or saved by this page.

Conversion mode
Input mode

Hex digits (0–9, a–f) are converted to bytes before encoding. Whitespace is ignored. An odd number of digits is padded with a trailing 0 to form whole bytes; for example, abc becomes abc0. Leading zeros are preserved.

The file’s original bytes are encoded. Large files take longer and produce much larger output.

Text is encoded as UTF-8, including whitespace. There is no fixed input size limit, but large files take longer and produce much larger output.

Uses the same binary format as Secure file encryption: AES-256-GCM and PBKDF2-SHA-256 with 600,000 iterations. The filename is encrypted too. Keep your password separately; it cannot be recovered.

Yeti output





Each row includes a sum-modulo-58 checksum. The final five digit words encode the last two bytes of SHA-256 over the word rows. No checksum prefix is required or added. This format is raw bytes, not WIF or an original Yeti wallet recovery seed.








Decode Yeti words


Enter one row per input, or paste multiple lines. Each data row has four words plus its checksum; the final data row may be shorter. The last row is always the five uppercase digit words of the final checksum. Case matters. Automatic validation runs when you leave an input. Use ↑/↓ to select a suggestion, Enter or Tab to accept, and Escape to dismiss. With suggestions closed, Enter adds a row.
