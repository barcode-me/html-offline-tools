Passwords and TOTP

Open your passwords and live authentication codes, all in one place.

Runs entirely in your browser. Nothing is sent over the network or saved by this page. Codes use your device clock.

Input mode

When decrypting sensitive passwords or 2FA secrets from a GPG-encrypted file, use the following command and copy and paste the encrypted Base64 string to avoid placing unencrypted content in the filesystem or clipboard. You can use a temporary password just for the transfer: make one up on the spot that you can easily type into both this HTML page and the CLI password prompt.

gpg --decrypt ~/test.txt.gpg | node secure-file-encryption.js

Paste the encrypted Base64 produced by Secure file encryption or its Node.js script.
